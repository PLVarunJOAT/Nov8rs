# Nov8rs (Innovators) website

## Deploy to Vercel (2 minutes)
1. Go to vercel.com → Add New → Project → drag in the `nov8rs-site` folder (or push it to a GitHub repo and import it).
2. Framework preset: "Other". No build command. Output directory: leave empty.
3. Deploy. Clean URLs, redirects, caching and security headers come from `vercel.json`.
4. While on a *.vercel.app address the site sends `noindex`, so Google won't index the staging copy. It indexes normally once nov8rs.com points to Vercel.

## Before going live
- Contact form: paste your GHL inbound webhook URL into `formEndpoint` at the top of `assets/js/site.js`.
- Analytics: paste your GA4 / GTM snippet where the comment says "Analytics" in each page head (or in `build_lib.py` and rebuild). Quote clicks push `quote_click` to dataLayer.
- Legal: privacy.html and terms.html are drafts with [PLACEHOLDERS]; they are set to noindex.
- Confirm the email hello@nov8rs.com.
- Replace placeholder examples: "[Your business]", case-study slots, "90+" speed target, "4.9" rating and "24" leads in demos.

## Editing
Pages are generated by `nov8rs-site-source/build.py`. Edit copy there, then run `python3 build.py` (needs Python 3 + Pillow) to regenerate `dist/`.
